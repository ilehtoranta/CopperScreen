# CopperStart native Intuition and Railroad Tycoon — 2026-10-18

Native Intuition runs in the guest ROM. The rebuilt image completes Railroad Tycoon setup, A/B/A disk swaps and world generation in both CPU modes. All 2,255 capture files match across the completed 180,000-frame runs. Full gameplay remains unqualified.

Source: CopperStart commits [0f0adc9](https://github.com/ilehtoranta/CopperStart/commit/0f0adc9a9f3bacd3c7c0a51258599d93b2937849) and [941e9c4](https://github.com/ilehtoranta/CopperStart/commit/941e9c475e148ee115217deb615997ae5ed0bfc0) (final tree `df647c61f1fb418451741254cf6f1379b7ba3c13`). ROM/media/build outputs remain local artifacts.

This change adds a guest MC68000 Intuition resident at $FF4000 and extends native graphics at $FF8000. Screens, full-screen borderless windows, IntuiText, pointers and raw keyboard/mouse/disk IDCMP messages run in the ROM. No CPU/chipset change, host OS shim, title patch or media modification participates.

The console publishes an actual Screen and Window backed by its terminal bitmap. ACTION_DISK_INFO exposes that Window in id_VolumeNode. The active native window owns physical keyboard delivery while console packets remain serviced. Borrowed CUSTOMBITMAP descriptors and planes retain public Classic layouts. Owned records, rasters, fonts, ports and sprite buffers retain allocation-failure cleanup and lifetimes. IORequest mn_Length and hidden caller-allocation markers do not establish legitimacy.

Native OpenLibrary/OldOpenLibrary search registered libraries, then use DOS LoadSeg and Exec InitResident for LIBS: or explicit paths. CloseLibrary/RemLibrary unload returned segment lists. Railroad supplies its original diskfont.library and five font files. Its non-AUTOINIT initializer registers a library and returns TRUE: the loader resolves registered rt_Name rather than treating the initializer result as a library base. No synthetic diskfont provider is installed.

Window ports and 52-byte IntuiMessages are real guest Exec objects. A permanent input task acknowledges CIA keyboard data, handles qualifiers, publishes mouse events and polls the physical DF0 change latch. TD_CHANGENUM/TD_CHANGESTATE extend native BeginIO through SetFunction; other commands retain their installed handler. Detaching Window.UserPort with NULL leaves its cleanup with the caller. ModifyIDCMP(0) retires currently owned ports and signals.

The native filesystem receives a private media signal and refreshes before ordinary application tasks consume insertion. It invalidates track cache and publishes volumes by name plus creation DateStamp. Removed nodes remain offline for existing locks; reinsertion reuses the original node and LockList. Host cases cover different stamps, same names and another Process holding a valid DOS-list read lock. The real ROM window probe swaps OFS/FFS disks with different payloads, reads both, and returns to the original volume identity.

The new input path exposed two Exec defects. Switching inside VBlank Signal could save an interrupt handler as a task continuation. Deferring that switch still allowed IRQ Signal to race foreground ready-list updates. The earlier media-enabled ROM (SHA-256 30515391d4571e34c4dd8baf943debe8535c02c9f920feb16588a2fa1f7eae82) loads disk B and the credits but leaves the input task marked READY and detached from the ready list. At frame 73,600, Railroad is polling mouse/keyboard on a black screen with no disk I/O. Its normal/scalar 96,000-frame runs have all 1,205 capture files identical, and remain NEGATIVE despite clean exits.

Exec now makes internal task/list transactions interrupt-atomic. It restores the physical interrupt master before guest callbacks, idle or dispatch, preserving direct INTENA ownership and Enable nesting behavior. Higher-priority tasks dispatch after the outer user IRQ return or an eligible completed Exec call. GetMsg uses that completion boundary, preserving its original result across a switch. Disable and Forbid defer running-task rescheduling; Wait saves each task's nesting, breaks it while another task or idle runs, and restores it on resumption. IRQ-return cases preserve D0–D7/A0–A6, user SP, PC and CCR; nested supervisor interrupts retain their return.
