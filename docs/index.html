Get started

Onboarding guideBuild from source
  1. Open CopperScreen and select your Amiga model.
  2. Select Start Amiga and insert a compatible boot floppy when prompted.

For Workbench or an HDF hard disk, select an original Kickstart ROM using Choose ROM….

CopperDisk

CopperDisk is a .NET 10 Amiga disk-image library with managed SPS/CAPS IPF decoding. It exposes encoded track streams and a best-effort AmigaDOS sector view for emulator hosts and disk tools. A native CAPS library is not required.

CopperDisk API and IPF support

Development

CopperScreen is written in C# and uses an Avalonia desktop interface and the Copper68k CPU interpreter. The emulator, disk library, tests and headless runner are open source.

Timing accuracy and compatibility are ongoing work. Some interlaced output remains unstable. A screenshot demonstrates a captured scene, not complete compatibility with that title.
