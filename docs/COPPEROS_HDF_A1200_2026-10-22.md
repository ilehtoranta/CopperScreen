# CopperOS HDF on A1200

This is the historical Shell proof qualification. The launcher now bundles the
[native desktop HDF](COPPEROS_DESKTOP_A1200.md); the ROM identity below is retained.

The supported configuration is PAL Alice/Lisa, the accurate 68EC020 interpreter,
2 MiB Chip RAM, no slow or Fast RAM, and one FFS HDF on unit 0 with empty floppy
drives. The start menu is unchanged. Use an existing personal profile or Settings
to select the machine, CopperStart ROM and HDF. This qualification concerns the
original CopperOS Shell system, not the graphical desktop.

## Firmware and media

The [A1200 artifact contract](../CopperScreen/Firmware/CopperStartA1200.json)
selects a separate firmware hash from the existing A500 contract. Raw files and
single-ROM ZIPs use the same size and SHA-256 verification. Selecting A1200
retains the CopperStart boot method, offers the qualified 68EC020 CPU, and
validates the A1200 firmware rather than requiring proprietary Kickstart 3.0.

| Input | Identity |
| --- | --- |
| A1200 ROM | `diskboot-2026-10-22-a1200-hdf.1`, 1,048,576 bytes |
| ROM SHA-256 | `e7631f0ead8165bd53f9db7450d6e58cc5b58dfb216b35e29c17c433f9593165` |
| Pristine CopperOS HDF SHA-256 | `54c6f78a7480437069b66a5f913c5ccde76fc3e604babeb1dc22674360242175` |
| HDF layout | 8 MiB raw DOS1 FFS partition, 512-byte blocks, `DH0:2:32:0:255` |

The HDF is byte-identical to the [A500 proof image](COPPEROS_HDF_A500_2026-10-22.md).
The ROM is separate from the disk. Its first 512 KiB map at E00000 and contain
graphics at E60000; its second 512 KiB map at F80000 and contain the reset ROM.
Both mappings use existing Lightweight APIs. Companion ROM files cannot replace
the integrated A1200 graphics bank. There are no host DOS callbacks or emulator
CPU/chipset changes.

CopperStart now captures user SR through a real supervisor exception frame on
68010-compatible CPUs, and constructs the format/vector word when handing off
to a user boot block. The 68000 path retains its original instruction sequence.
The integrated graphics bank accommodates the current 502,102-byte native core
without removing filesystem features. Native allocation/helper gates remain
clear. Build it in CopperStart with `build/Build-DiskBootRom.ps1 -A1200`.

## Local launch and replay

The local system is under the sibling repository's ignored directory:
`../CopperOS/artifacts/hdf-a1200-20261022/system/`.

- `CopperOS.hdf` is the pristine image.
- `CopperOS-Workspace.hdf` is a separate writable copy for use.
- `CopperOS-A1200.json` is a normal personal app profile.
- `Start-CopperOS.ps1` launches the production local build with that profile.
- `app-proof/` contains native captures, state observations and result records.

From this checkout:

```powershell
& ../CopperOS/artifacts/hdf-a1200-20261022/system/Start-CopperOS.ps1
```

The optional native tests require `COPPERSCREEN_COPPERSTART_A1200_ROM` to point
to the qualified combined ROM and `COPPERSCREEN_COPPEROS_HDF_PROOF` to the system
directory containing the HDF and receipt. Filter for
`CopperOsBootProofTests.A1200`. The A500 tests retain their separate
`COPPERSCREEN_COPPERSTART_ROM` variable and original firmware hash.

Tests drive normal session creation and raw keyboard events, and read actual
guest console pixels. The input driver waits for a complete native Shell prompt
before typing another command. Cold reopen disposes the entire writing session.
ROMs, media and receipts remain local artifacts; no package release is included.

## Verified results

| Coverage | Result |
| --- | --- |
| Emitted CPU instructions | Both new 68EC020 SR-capture cases passed, covering user and supervisor callers, caller flags, saved registers and stack balance. The original 68000 byte-image and supervisor cases also passed. |
| Producer ROM/graphics | 7 passed, no skips: 6 full native boot/graphics cases across 68000 and A1200, plus 1 host composition/checksum case. `CopperStart/artifacts/a1200-20261022/results/rom-extended-smoke.trx`. |
| A1200 app | 15 passed, no skips: 13 host configuration cases and 2 full native HDF cases. The latter cover read-only startup plus reset, writable startup, and a fresh session reopening the written disk. `artifacts/copperos-a1200-20261022/a1200-verified.trx`. |
| A500 app regression | 14 passed, no skips: 10 host cases and 4 native cases, retaining the original A500 ROM. HDF persistence, read-only HDF, ADF and standard-session boot/reset/reinsert/restart passed. `artifacts/copperos-a1200-20261022/a500-regression.trx`. |
| Persisted HDF | Independent verification passed for exact paths, payload hashes, block ownership, checksums and the full allocation bitmap. The boot checksum is checked on the original image; the generic filesystem reader normalizes only a private copy of its custom boot block. |
| Builds | CopperScreen production solution: zero warnings/errors. CopperStart solution: zero errors, 20 existing dependency/library warnings. Both were Release builds with isolated artifact paths. |

The A1200 native cases exercised Alias, an external Demo and return to Shell,
unknown-command recovery, native DOS write protection, settings/data writes,
rename/delete, and relative file/directory operations. A fresh machine read the
written settings and data successfully without modifying the HDF further.
The saved image SHA-256 is
`590301973add58f7059ad708f20ac7c65dabe9708e344e1b30884f9a8a722a91`, identical
to the image produced by the same storage operations on A500.

Successful A1200 captures are in `app-proof/20261021T224616456Z-a1200-hdf-readonly/`,
`20261021T224921625Z-a1200-hdf-write/` and
`20261021T225057755Z-a1200-hdf-reopen/`. The local launcher uses the exact Release
app binary exercised by these replays. The independent result is
`persisted-filesystem-verification.json` beside the system image.

The wider Exec suite passed 58 of 59 cases. Its low-memory test
`CompiledDirectLowMemoryRecoveryExpungesOnlyUnusedDelayedLibraries` still fails
because the expected expunge callback is not observed. An isolated replay with
the original `HEAD` Exec vector/bootstrap sources reproduced the same failure;
it is not resolved by this A1200 change. See the producer's
`results/exec-vector-verified.trx` and `results/baseline-expunge.trx`.
