Amiga disk-image library

CopperDisk

A .NET 10 library for ADF, extended ADF, ADZ, DMS, IPF and SCP images. The managed SPS/CAPS IPF decoder exposes encoded track data and a best-effort AmigaDOS sector view for emulator hosts and disk tools.

IPF decoding

IpfDecoder.Decode returns an IpfDiskImage containing individual IpfTrack objects. It supports CAPS/SPS container encoders, MFM/raw track blocks and stored IPF gap streams. Encoded track access retains nonstandard disk layouts that cannot be represented by ordinary sector ADF images.

Track representation

Tracks expose encoded bytes, meaningful bit lengths, index positions and feature flags. AlignTracksToWord = false retains exact bit lengths; its default is true.

Media interface

AmigaDiskLoader returns IAmigaSectorDiskMedia with encoded track access and decoded AmigaDOS sectors. IpfDecoder provides the IPF-specific model directly.

Runtime dependencies

The implementation is managed C#, targets .NET 10 and has no external runtime dependencies. A native CAPS library is not required.

Density timing metadata

IpfTrack.DensityType exposes the SPS density selector. Optional CellWeights provide index-oriented relative bit-cell durations with a nominal weight of 1000. Hosts normalize the sum to one revolution. Density timing metadata, stored IPF gap streams and weak/no-flux regions are available in the stable 3.0.0 package.

Source projectAPI guide
Decode an IPF imageC#
using CopperDisk;

var image = IpfDecoder.Decode(
    File.ReadAllBytes("disk.ipf"),
    new IpfDecodeOptions
    {
        AlignTracksToWord = false,
        StartAtIndex = true
    });

foreach (var track in image.Tracks)
{
    Console.WriteLine(
        $"{track.Cylinder}/{track.Head}: {track.BitLength} bits");
}

AmigaDiskLoader.Load("disk.ipf") loads file-backed media; FromIpfBytes accepts in-memory data. Both accept optional IpfDecodeOptions. ZIP loading accepts an archive containing exactly one supported disk image.

IPF limitations

Decoder notesCopperScreen integration

IPF loading is read-only. The decoder supports the SPS/CAPS stream forms used by CopperScreen; unknown encoders and malformed streams fail explicitly.

Weak-data bytes are materialized deterministically and marked as approximate. Emulator hosts must handle weak-region variation and controller timing. Successful decoding alone does not guarantee that every copy-protection scheme will work.

The AmigaDOS sector view is best-effort: unreadable sectors are zero-filled. Check HasCompleteDecodedSectorData before treating it as a complete sector image.
