# Supplied AGA games: native startup investigation

The supplied folder contains UFO: Enemy Unknown (four disks) and Alien Breed
3D II: The Killing Grounds (five disks). Both boot on the stock PAL A1200
profile. Missing native 020 operand forms prevented even startup with public
Copper68k 1.5.1. The accumulated fixes are committed to CopperMod main as
[`964e0b9`](https://github.com/ilehtoranta/CopperMod/commit/964e0b9a3ffa2df6d41666af6ce2bb93a4957208).
The packed **1.5.2 development candidate remains unpublished**. CopperScreen
still pins public **1.5.1**; none of the candidate results below describe the
unchanged application's current package behavior.

The [machine-readable record](AGA_GAMES_2026-10-02.json) retains archive/member
identities, commands, package/source/binary hashes, captured state and all
normal/scalar comparisons. Local ROMs, game media, captures and packages remain
ignored. No game executable, startup script or disk was patched.

## Inputs and machine

Media was supplied at `C:/Users/ilkle/Koodit/TestData/Test Images - AGA/`.
Each ZIP contains one 901,120-byte FFS ADF. The titles are distinct from the
earlier Alien Breed II: The Horror Continues investigation.

The machine uses native A1200 Kickstart 3.0, revision 39.106, 68EC020, Alice/Lisa,
2 MiB Chip RAM and zero Slow/Fast RAM. UFO uses its four supplied disks in
DF0–DF3. Alien Breed uses disk 1's **2 MiB program**, disk 3's levels and disk 4's
sound in DF0–DF2; the alternate 4 MiB program and editor disks are unused.
This selects the stock-machine build described in the
[original Alien Breed 3D II manual](https://www.gamesdatabase.org/Media/SYSTEM/Commodore_Amiga/Manual/formated/Alien_Breed_3D_II-_The_Killing_Grounds_-_1996_-_Ocean_Software_Ltd..htm).
UFO's [original technical supplement](https://openretro.org/file/35eb49586dc283dfa050cd5946c40a9b1be9919c/TechnicalSupplement_ocr.pdf)
requires an AGA A1200/A4000 and 2 MiB RAM and describes native floppy startup.

UFO's supplied startup first runs the PRESTIGE crack intro (`BlahBlah`), then
SetPatch and the UFO/Geo launcher. Alien Breed starts `intro.exe`, followed by
`tkg1:tkg`. Intro execution alone does not establish AGA-required gameplay.

## CPU correction and remaining failures

Both original 1.5.1 replays stop in Kickstart at `$FA1CB2`, opcode `$B388`,
`CMPM.L (A0)+,(A1)+`. CMPM.W/L and subsequently reached operand forms were
implemented in the shared Copper68k advanced executor. The forms cover sized
ADD/SUB/ADDA/ADDI, AND, CLR/NOT/TST, MOVE, MOVEM.W indirect, dynamic BCLR/BSET,
ADDQ.W absolute-long and SUBX.B/W registers. These are general opcode/operand
implementations, with no title-specific dispatch, delay, fallback engine or
extra device clock. The existing operand-shape timing policy remains approximate.

Focused regressions check extension-word PC bases, signed/scaled brief indexes,
widths, sign extension, aliased registers, A7 byte stride, sticky SUBX zero,
extend/borrow/overflow, condition-code preservation and surrounding memory.
MOVEM tests retain both the 000/010 ignored-tail behavior and an independent
040 integer-fallback control. New RMW plans retain their barriers.

| Replay with the candidate package | Result |
| --- | --- |
| UFO intro, no input, 4,000 fields | Completed with graphics and nonzero PCM; all 55 capture files match scalar execution. |
| UFO, left mouse down at field 1200 and up at 1240 | Intro exits normally. At field 2286 the loader/game startup stops at `$654CE`: `$2034`, extension `$0162`. All 37 capture files, including the failure field, match scalar execution. |
| Alien Breed 3D II, natural startup, 2,500-field bound | Stops at field 1346, `$3B076`: `$90B9`, `SUB.L (xxx).L,D0`. All 37 capture files, including the failure field, match scalar execution. |

UFO's `$0162` extension selects **full-format memory-indirect addressing** with
index suppressed, a word base displacement `$02E0` and a word outer displacement
`$0018`. Its source is `ReadLong(ReadLong(A4 + $02E0) + $0018)`; treating the
extension as an eight-bit displacement would read the wrong operand. The current
executor stops after consuming the extension, before that pointer read. A small
regression preserves the explicit unsupported boundary. The proper next change
belongs to the shared CPU effective-address implementation, including extension
consumption, pointer-read ordering, suppression, displacement widths, invalid
encodings and the declared timing policy. It needs a separate native replay.

Alien Breed's next gap is ordinary absolute-long subtraction. Neither failure
is evidence of an AGA display regression. Earlier failures and intermediate
captures remain available separately; they are not rewritten as passing evidence.
Architectural expectations follow Motorola's
[programmer reference](https://www.nxp.com/docs/en/reference-manual/M68000PM.pdf)
and [MC68020 user manual](https://www.nxp.com/docs/en/data-sheet/MC68020UM.pdf).

## Reproduction and follow-up

Use the runner options recorded in the JSON. For either title, select
`--cpu 68ec020 --agnus alice --denise lisa --chip-ram-kib 2048 --slow-ram-kib 0`,
the native A1200 ROM and the drive layout above. Enable `--boot-probe`,
`--boot-probe-extended`, and a 500-field UFO or 300-field Alien Breed capture
interval. Add `--scalar-cpu` for the paired control. UFO's normal exit input is
retained in [the workload](../../CopperScreen.Lightweight.Tests/Workloads/aga-ufo-intro-exit.json).
The existing OCS-only native-regression schema is unchanged; these A1200 runs
are a separately recorded investigation.

Complete the missing shared CPU addressing/operand forms, then repeat native
startup to actual AGA game screens and input-responsive gameplay. Disk swaps,
save/load, complete games, every display mode, and physical A1200 CPU/cache/bus
timing remain unverified. See [current issues](ISSUES.md).
